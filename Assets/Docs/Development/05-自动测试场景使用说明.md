# 自动测试场景使用说明

## 场景目标
用于快速验证以下脚本链路是否可运行：
- 主角移动与双武器输入
- 小怪主动攻击
- 伤害上下文与事件总线
- 击杀后掉落与拾取
- 道具叠层效果

## 已生成资源
- 场景：Assets/Scenes/ScriptValidation_Auto.unity
- 道具资源：Assets/Items/Generated/itm_damage_mark.asset
- 道具资源：Assets/Items/Generated/itm_crit_lens.asset
- 编辑器构建器：Assets/Editor/BuildScriptValidationScene.cs

## 在 Unity 编辑器中打开
1. 打开 Project 窗口中的 Assets/Scenes/ScriptValidation_Auto.unity。
2. 点击 Play。
3. 默认按键：
   - 左右移动：A/D 或方向键
   - 跳跃：Space
   - 近战：J
   - 远程：L

## 验证点
1. 玩家可以移动、跳跃、近战、远程。
2. 小怪会在附近主动攻击玩家。
3. 击杀小怪后会有概率掉落道具拾取物。
4. 玩家拾取后，道具层数增加并通过事件广播。
