# 共享接口文档 v0.1（主角/敌人/道具）

## 1. 文档目的
为三人并行开发提供稳定契约：
- 模块内部可自由重构
- 跨模块只通过数据结构、事件和服务接口通信
- v0.1 只允许新增字段，不允许破坏既有语义

## 2. 共享数据结构（Data Contracts）

### 2.1 CombatContext
```csharp
public enum DamageType { Melee, Projectile, Skill, Dot, Reflect }

public struct CombatContext
{
    public int attackerId;
    public int targetId;
    public float baseDamage;
    public DamageType damageType;
    public float critChance;
    public float critMultiplier;
    public UnityEngine.Vector2 knockback;
    public UnityEngine.Vector3 hitPoint;
    public string sourceTag;
    public float timestamp;

    public UnityEngine.GameObject attackerObject;
    public UnityEngine.GameObject targetObject;
}
```

说明：
- 攻击发起方创建 CombatContext。
- 道具系统可在伤害提交前改写 baseDamage、critChance、critMultiplier。

## 3. 事件契约（BattleEvents）

```csharp
public static class BattleEvents
{
    public static System.Action<CombatContext> OnAttackStarted;
    public static System.Action<CombatContext> OnAttackResolved;

    public static BeforeDamageAppliedHandler OnBeforeDamageApplied;
    public static System.Action<CombatContext, HealthSnapshot> OnAfterDamageApplied;

    public static System.Action<UnityEngine.GameObject, UnityEngine.GameObject, CombatContext> OnParrySuccess;
    public static System.Action<UnityEngine.GameObject, CombatContext> OnEnemyDied;

    public static System.Action<string, int> OnItemPicked;
}
```

```csharp
public delegate void BeforeDamageAppliedHandler(ref CombatContext ctx);
```

事件语义：
- OnAttackStarted：攻击动作开始（前摇触发点）。
- OnBeforeDamageApplied：伤害提交前窗口（用于修正）。
- OnAfterDamageApplied：扣血后回调。
- OnEnemyDied：敌人死亡后回调（掉落、统计、进度）。

## 5. 所有权与调用边界

### 5.1 主角负责人
- 拥有 PlayerController 的输入与动作实现。
- 必须发射攻击相关事件。
- 不直接处理敌人掉落概率。

### 5.2 敌人负责人
- 拥有 EnemyBase/MinionEnemy/BossEnemy/EnemySpawner。
- 敌人受击统一消费 CombatContext。
- 不直接写玩家属性。

### 5.3 道具负责人
- 拥有 ItemData/RunInventory/ItemEffectService/DropService。
- 通过事件和接口改写战斗，不侵入主角与敌人私有逻辑。

## 6. 标准调用时序（必须遵循）
1. 攻击方创建 CombatContext，触发 OnAttackStarted。
2. Damageable 在真正扣血前触发 OnBeforeDamageApplied。
3. Damageable 执行无敌、招架、扣血、死亡判定。
4. 触发 OnAfterDamageApplied。
5. 若目标死亡且为敌人，触发 OnEnemyDied。
6. 道具系统执行 RollDrop/SpawnDrop，拾取后触发 OnItemPicked。

## 7. 联调验收用例（跨团队）
- 用例 A：近战连段可命中小怪并触发 OnEnemyDied。
- 用例 B：远程技能命中 Boss，伤害可被道具叠层放大。
- 用例 C：招架成功后触发 OnParrySuccess，敌人进入受击反馈。
- 用例 D：击杀后掉落道具并拾取，主角属性立即变化。
- 用例 E：运行 10 分钟后新刷敌人强度明显提升。
