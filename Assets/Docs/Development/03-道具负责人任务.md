# 道具负责人任务说明（遗物/掉落/叠层）

## 1. 目标
在 1-2 周内交付最小可行道具系统：
- 道具可掉落、可拾取、可叠层
- 道具效果可改写战斗结算（不侵入主角/敌人私有实现）
- 支持最小局外成长的存档基础（仅 ID 与等级）

## 2. 你拥有的模块
- 新增：ItemData（ScriptableObject）
- 新增：RunInventory（局内道具容器）
- 新增：ItemEffectService（战斗修正服务）
- 新增：DropService（掉落服务）
- 接入点：Assets/Scripts/Core/Damageable.cs、Assets/Scripts/Enemies/EnemyBase.cs、Assets/Scripts/Systems/EnemySpawner.cs

## 3. 本线任务清单

### Day 1-2：数据与运行时骨架
- 建立 ItemData 配置（id、名称、稀有度、最大层数、效果参数）
- 建立 RunInventory（道具增减、叠层、查询）
- 建立 ItemEffectService（按事件触发效果）

### Day 3-4：战斗链路接入
- 接入 OnBeforeDamageApplied，支持伤害/暴击/冷却修正
- 接入 OnAfterDamageApplied，支持受击后触发类道具
- 接入 OnEnemyDied，支持击杀触发类道具

### Day 5-6：掉落与拾取
- 实现 RollDrop(enemyType, threatLevel)
- 实现 SpawnDrop(dropId, position)
- 拾取后更新 RunInventory，并广播 OnItemPicked

### Day 7-8：联调修正
- 与主角线验证道具叠层对主角属性的实时影响
- 与敌人线验证死亡触发与掉落概率
- 修复重复触发、层数溢出、同帧多次结算问题

## 4. 首版必须实现的 4 个道具效果（建议）
- 狂战印记：每层 +X% 伤害
- 冷凝核心：每层 -Y% 技能冷却
- 猎杀镜片：每层 +Z% 暴击率
- 破甲碎片：命中后对目标施加短时易伤

## 5. 你必须提供的接口能力
- ApplyItem(string itemId, int stackDelta)
- RemoveItem(string itemId, int stackDelta)
- EvaluateDamageModifiers(ref CombatContext ctx)
- RollDrop(string enemyTypeId, float threatLevel)
- SpawnDrop(string dropId, Vector3 worldPos)

## 6. 完成标准（DoD）
- 至少 4 个道具效果可叠层且可回滚
- 击杀后可稳定掉落并拾取
- 道具不直接写 PlayerController/EnemyBase 私有字段
- 重启后可读取最小局外成长数据（仅永久项）

## 7. 非目标（先不做）
- 全套道具图鉴与复杂UI
- 深度随机词条系统
- 大规模经济系统（商店、重铸等）

## 8. 已提供首个实现（可直接参考）
- 道具配置：Assets/Scripts/Items/ItemData.cs
- 局内背包：Assets/Scripts/Items/RunInventory.cs
- 道具效果服务：Assets/Scripts/Items/ItemEffectService.cs
- 掉落服务：Assets/Scripts/Items/DropService.cs
- 可拾取物：Assets/Scripts/Items/ItemPickup.cs

已实现内容：
- 支持道具叠层与拾取事件广播（OnItemPicked）
- 支持伤害前改写（DamagePercent / CritChanceFlat / CritMultiplierPercent）
- 支持击杀回血类效果（OnKillHeal）
- 支持按敌人类型与威胁等级进行掉落判定

快速测试步骤（首版）：
1. 给玩家对象添加 RunInventory 与 ItemEffectService。
2. 在场景添加 DropService，并配置 dropRules。
3. 敌人死亡后应有概率生成拾取物，玩家触碰后叠层生效。
